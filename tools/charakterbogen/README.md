# Online-Charakterbogen

Geplante Funktionen:

- Attribute, Titel (Level, Domäne, Leitattribute) und automatisch berechnete Meisterschaft
- Energie, Willenskraft und Momentum mit Maxima und Deckel
- Körpersilhouette mit Verletzungen (Kopf 2, Torso 3, Gliedmaßen 2). Vorlage: [`assets/grafiken/koerper-silhouette.svg`](../../assets/grafiken/koerper-silhouette.svg), dieselbe Grafik wie im Regelwerk (2.3); Zonen und Felder sind einzelne SVG-Elemente und lassen sich direkt ansteuern
- Schutz, Waffen-Profile und Tags
- Move-Liste mit EP, Mindestlevel, Kosten und "gelernt auf Level"
