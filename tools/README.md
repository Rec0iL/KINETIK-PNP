# Tools

Digitale Helfer für KINETIK. Alle Tools sollen ihre Regelwerte aus `../data/` lesen, damit eine Regeländerung nur an einer Stelle gepflegt werden muss.

| Tool | Zweck | Stand |
|---|---|---|
| `charakterbogen/` | Online-Charakterbogen für Spieler | geplant |
| `sl-dashboard/` | Kampfverwaltung und Übersicht für den Spielleiter | geplant |
