# SL-Dashboard

Geplante Funktionen:

- Seiten-Initiative mit Kinetik-Marker
- Gegnerverwaltung nach NPC-Leiter (Goon-Gruppen, Elite, Boss)
- Bedrängnis-Zähler pro Spielercharakter
- Clash-Rechner mit Helden-Schwelle, Schutz-Schwelle und Außer Reichweite
- Übersicht über Tags, Verletzungen und Zustände aller Beteiligten
