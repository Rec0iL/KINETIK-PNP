# Regeldaten

Maschinenlesbare Fassung der Regeln als gemeinsame Quelle für alle Tools. Geplante Dateien:

| Datei | Inhalt |
|---|---|
| `tabellen.json` | Meisterschaft nach Level, MW-Skala, Momentum-Deckel |
| `ep-katalog.json` | Effekte und EP-Werte aus Kapitel 5.1 |
| `moves.json` | Beispiel-Moves |
| `waffen.json` | Waffen-Profile |
| `npc.json` | NPC-Leiter |
| `tags.json` | Kleine und große Tags |
